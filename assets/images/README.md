# 이미지 폴더

현재 제공된 이미지가 홈페이지에 연결되어 있습니다.

- `logo.png` 또는 `logo.svg`: 헤더 워드마크 교체용
- `hero-01.jpG`: 히어로 슬라이드 1 및 우유 제품 카드
- `beannbean.png`: 히어로 슬라이드 2 및 콩앤콩 제품 카드
- `erom.png`: 히어로 슬라이드 3 및 이롬 제품 카드
- `orion.jpg`: 온라인 유통 채널 카드 배경
- `product-soy.jpg`, `product-seaweed.jpg`, `product-nut.jpg`: 제품 카드용

추가 이미지를 넣을 때에는 영문 소문자·숫자·하이픈 형태의 파일명을 권장합니다.
